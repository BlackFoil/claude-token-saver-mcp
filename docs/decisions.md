## DS-002: キュー方式

| 項目 | 内容 |
|:---|:---|
| **日付** | 2026-02-15 |
| **提案者** | Architect |
| **決定** | Promise-based FIFO（同時実行1、最大キュー10件） |
| **理由** | ローカルLLMはGPU排他利用が前提のため、同時実行1に制限。外部依存なし（Redis等不要）でシンプルに実装 |

### パラメータ

- `maxQueueLength`: 10
- `maxRequestSizeBytes`: 200 KB
- `queueTimeoutMs`: 30,000 ms
- オプション: レートリミッター（RPM制限）

## DS-003: Ollama通信方式

| 項目 | 内容 |
|:---|:---|
| **日付** | 2026-02-15 |
| **提案者** | Coder 2 |
| **決定** | Node.js native `fetch` + NDJSON streaming |
| **理由** | 外部HTTP依存ゼロ（axios/node-fetch不要）。Node.js 20標準のfetchで十分。ストリーミングにより応答トークンをリアルタイム処理可能 |

### タイムアウト設計

| タイムアウト | 値 | 用途 |
|:---|:---:|:---|
| `requestTimeout` | 60s | リクエスト全体の上限 |
| `heartbeatTimeout` | 30s | チャンク間の無応答検知 |
| `firstTokenTimeout` | 120s | 初回トークンまで（モデルロード含む） |

AbortControllerで各タイムアウトを独立制御。
